# Rotsvast — Groningen

Поиск: https://www.rotsvast.nl/huren/?search=Groningen&price_to=1500

Критерии: Groningen, отдельное жильё без комнат и парковок, объявленная месячная аренда до €1500 включительно, без ограничения даты публикации. Дополнительные расходы из описания к цене не прибавляются. Цена берётся из карточки (`p.m.`) и сверяется с верхней ценой страницы объекта; поля Kale huur / Totale huur не подменяют объявленную цену.

## Выполнение

- Source ID: `rotsvast:groningen-homes`.
- Детерминированный публичный HTTP GET, без аккаунта, cookies, браузерного worker и LLM. `robots.txt`, проверенный 19 октября 2026, не запрещает `/huren/`; это не подтверждение отдельных условий использования.
- Включён по умолчанию. `ROTSVAST_MONITORING_ENABLED=false` отключает расписание без сброса истории. Общий интервал `MONITOR_INTERVAL_SECONDS` по умолчанию 900 секунд.
- Общий runner обеспечивает PostgreSQL lease, cooldown, отдельный тихий baseline и transactional Telegram outbox. Новых миграций нет.
- В админке доступны цена от/до, минимальная площадь и pause. Верхняя цена передаётся в `price_to` и повторно проверяется локально; нижняя цена и площадь проверяются локально. Изменение фильтров использует общий тихий проход новой revision.
- Каждая проверка читает все страницы, затем детали всех карточек, включая сданные. Детали нужны для типа жилья: например, `Appartement, Studentenkamer` исключается. Только известные сочетания типов самостоятельного жилья допускаются; неизвестные типы исключаются.
- Доступность требует явного `Direct beschikbaar` либо календарно корректного `Beschikbaar vanaf DD-MM-YYYY` в карточке и отсутствия неизвестных классов/бейджей. `Topper`, `Topwoning`, `Nieuw` — рекламные бейджи и сами по себе не доказывают доступность. `Verhuurd`, `Verhuurd onder voorbehoud`, `Onder optie`, `In optie`, `Gereserveerd` в карточке или галерее деталей означают unavailable. Unknown не уведомляется. Доступность отражает данные сайта.
- Проверяются canonical, активный URL grid с параметрами поиска (input-поля заполняет JS), Groningen в городе и URL карточки, обе панели пагинации, номера/ссылки/последовательность страниц, размер промежуточных страниц, уникальность ID/URL до фильтрации, обязательные данные и совпадение деталей с карточкой по URL, адресу, городу, цене и площади.
- Только HTTPS `www.rotsvast.nl`; detail URL ограничен `/huren/<slug>-h<ID>/`. Редиректы не выполняются. Общий timeout 120 секунд, не более трёх попыток на сетевые ошибки и 502/503/504, ограничение тела 8 МиБ, пауза 300 мс между страницами/деталями. 403 блокирует источник, 429 даёт cooldown.
- Ноль без подтверждённого контракта пустой выдачи вызывает ошибку, как и отсутствие пагинации. Неподтверждённая пустота, частичный обход или сбой детали не изменяют baseline и последнюю успешную проверку. Неизвестная/неполная пагинация (включая сокращённую через многоточие) требует обновления адаптера.

## Проверка

```sh
node --import tsx --test test/rotsvast.test.ts
node --import tsx -e 'require("./src/sources/rotsvast-core.ts").collect().then(r=>console.log(JSON.stringify({inspected:r.inspected,matched:r.listings.length,available:r.available,pages:r.pages}))).catch(e=>{console.error(e.category||"LIVE_SMOKE_FAILED");process.exitCode=1})'
```

Live smoke не использует БД и не отправляет Telegram. Он также запускается отдельным workflow `Rotsvast live smoke` для PR. Fixture-файлы — сокращённые реальные карточки и детали от 19 октября 2026; доступная карточка из общей выдачи вне Groningen используется только для проверки реального формата даты доступности. Географический фильтр полного адаптера её не допускает.

Результат полного live smoke 19 октября 2026: `inspected=17`, `matched=13`, `available=0`, `pages=2`. Исключены три Studentenkamer и одно парковочное место; подходящие объекты помечены `Verhuurd`. Это проверка чтения источника, а не production baseline или доставки новых объявлений.

Сайт не публикует независимый общий счётчик в этой выдаче. Проверки пагинации не выявляют все изменения состава между запросами: например, исчезновение карточки на последней странице или перемещение объектов без дублей и изменения числа страниц. Нельзя заявлять snapshot-консистентность. Неизвестные типы жилья исключаются консервативно; описания не классифицируются. Отдельные service costs/общая цена пока не нормализуются. Production-проверка остаётся после merge и deployment.
