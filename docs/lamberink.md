# Lamberink

Источник: [арендная выдача Lamberink](https://lamberink.nl/wonen/aanbod?buy_rent=rent&order_by=created_at-desc&page=1).
Source ID: `lamberink:rental-homes`.

По указанию пользователя: дома и квартиры, без гаражей; все города и цены из ссылки, без ограничения даты публикации. Типы API `woonhuis` и `appartement`; продажа и `overig` исключаются. Двойное предложение `both` включает аренду, как в фильтре сайта.

Сайт использует публичный `GET https://lamberink.nl/api/properties/available.json`: весь каталог загружается одним ответом, Vue фильтрует и пагинирует его в браузере. Адаптер проверяет `count` до отбора, уникальность ID, структуру данных, ежемесячную цену, площадь и URL с соответствующим ID. Дома сортируются по `created_at` по убыванию. Для `publishedAt` используется только `publish_date`; время создания не подменяет дату публикации. Секреты, аккаунт и browser worker не нужны. robots.txt на 15.10.2026 не запрещает используемый endpoint; фильтрованные HTML-страницы по расписанию не запрашиваются.

Доступность подтверждается `beschikbaar` вместе с флагами API. `is_available=true` само по себе недостаточно: реальная квартира со статусом `verhuurd onder voorbehoud` тоже имеет этот флаг. Условно сданные, проданные, под опцией/торгом и запрещённые к публикации карточки не уведомляются. Неизвестный статус сохраняется как `unknown`, без уведомления. Неизвестная структура, неполный ответ, HTTP/challenge и ошибки не считаются пустым успешным проходом. Исчезновение из каталога не означает автоматического перехода в unavailable.

NestJS использует общий runner: PostgreSQL lease, интервал `MONITOR_INTERVAL_SECONDS` (900 секунд), отдельный baseline, transactional outbox и дедупликацию. Первый успешный проход не рассылает старые объявления. `LAMBERINK_MONITORING_ENABLED=false` выключает источник без сброса baseline. В админке доступны pause, минимальная/максимальная цена и минимальная площадь; ограничения применяются перед уведомлением после чтения полного каталога. Изменение фильтров использует существующее подавление исторических уведомлений.

Проверки:

```sh
node --import tsx --test test/lamberink.test.ts
npm run build
node scripts/lamberink-check.cjs
```

Последняя команда читает реальный каталог без БД и Telegram. На 15.10.2026: полный каталог 255 объектов, 3 арендных дома/квартиры, 2 доступны; гараж исключён, одна условно сданная квартира сохранена как unavailable. В fixture оставлены используемые поля пяти реальных объектов (продажа, дом, две квартиры, гараж), поэтому её count скорректирован до 5. Проверка не подтверждает запуск production scheduler или естественную доставку нового объявления.
