# Van der Meulen Makelaars

[Согласованные требования в Notion](https://app.notion.com/p/402d10c6e6ab818d8ac5cfb5835d1a21?pvs=204). Runbook описывает реализацию;
датированные результаты ниже относятся к конкретным проверкам, а не live-статусу production.

Источник: [пользовательская выдача](https://www.vandermeulenmakelaars.nl/huurwoningen/?_plaats=groningen&_status=nieuw&_prijsbereik=10.00%2C1500.00).
Source ID: `vandermeulen:groningen-nieuw`.

Фильтры: Groningen, статус Nieuw, объявленная месячная аренда €10–1500 включительно. Nieuw — статус сайта, а не дата публикации: ограничение «за сегодня» не добавляется. Тип жилья не ограничивается; комнаты тоже могут попадать в эту выдачу. Стоимость услуг в карточках не раскрывается и к цене не прибавляется.

Адаптер читает HTML обычным HTTP GET без аккаунта и browser worker. На 15.10.2026 robots.txt не содержит запрета на используемую выдачу; это не подтверждение отдельных условий использования. Фильтры передаются через `_plaats`, `_status`, `_prijsbereik`, страницы — `_paged`. По 12 карточек на страницу. HTML содержит публичные состояния FacetWP `FWP_JSON` и `FWP_HTTP`: проверяются точное эхо параметров, счётчик, номер страницы, размер страницы, количество страниц и полная выдача. Пустой результат принимается только с валидными метаданными и пустым контейнером карточек.

Из карточки читаются ID `h…` из URL, название/улица, город, площадь, число комнат и цена за месяц. Нидерландское `1.055` означает €1055. Дата публикации не выдумывается. Только явный значок Nieuw подтверждает доступность для уведомления; сданные/зарезервированные и неизвестные статусы не уведомляются. URL ограничены HTTPS, доменом `www.vandermeulenmakelaars.nl` и путём `/huurwoningen/…-hID/` без query/fragment.

Все страницы должны пройти проверку до сохранения. Изменение счётчика между страницами, дубликаты ID/URL, пропущенные карточки, повреждённые метаданные, challenge, HTTP-ошибка или неожиданный redirect завершают проход ошибкой. До 100 страниц, 8 MiB на ответ, 120 секунд на проход; до трёх попыток при сетевой ошибке и 502/503/504. Между страницами пауза 250 мс, 429 получает cooldown.

NestJS использует общий PostgreSQL lease, интервал `MONITOR_INTERVAL_SECONDS` (по умолчанию 900 секунд), отдельный baseline и transactional Telegram outbox. Первый полный проход сохраняет текущие объявления без рассылки. Админка предлагает цену от/до, минимальную площадь и pause. Цена применяется в поиске сайта, площадь — перед уведомлением. Изменение настроек использует штатное подавление исторических уведомлений. `VANDERMEULEN_MONITORING_ENABLED=false` выключает источник без сброса baseline.

Проверки:

```sh
node --import tsx --test test/vandermeulen.test.ts
npm run build
node scripts/vandermeulen-check.cjs
```

Последняя команда читает сайт без БД и Telegram. Первичная проверка: 1 объявление, Van Starkenborghstraat, €406/месяц, 15 м², 1 комната, Nieuw. Реальные fixtures содержат фильтрованную и пустую выдачи; пагинация дополнительно исследована на реальном каталоге (26 результатов, 3 страницы при снятом статусе), транспортные тесты используют синтетические страницы из реальной карточки.

Локально прошли 112 unit-тестов, TypeScript/build, React build, Prisma validate и live smoke. PostgreSQL integration добавлен; локальный запуск заблокирован read-only storage Docker, проверка выполняется в CI. Этот локальный набор не проверял production baseline и естественную доставку. Последующее подтверждение production baseline сохранено в архиве Notion; естественную доставку нельзя вывести из live smoke.
