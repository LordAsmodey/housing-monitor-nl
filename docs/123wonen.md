# 123Wonen — Groningen

Источник: https://www.123wonen.nl/huurwoningen/in/groningen

Source ID: `123wonen:groningen-homes`. Реализация: `src/sources/wonen123-core.ts`, runner и NestJS service рядом. Публичный HTTP GET без аккаунта, cookies и browser worker. LLM не используется. Миграций БД нет.

По умолчанию — отдельное жильё без комнат, объявленная аренда €0–1500 включительно, без ограничения даты публикации и площади. Эти критерии перенесены с последних источников; отдельного подтверждения для 123Wonen на момент реализации не получено. Минимальная/максимальная аренда, минимальная площадь и pause доступны через общий модуль админки. Цена и площадь проверяются на сервере после полного чтения исходной выдачи. Дополнительные расходы из описаний не прибавляются к цене. Комнаты и неизвестные/несогласованные типы жилья исключаются по типу карточки и URL. Описания отдельно не классифицируются.

Scheduler использует общий интервал (по умолчанию 900 секунд), PostgreSQL lease, отдельный тихий baseline, transactional Telegram outbox и дедупликацию. Первый успешный проход сохраняет текущую выдачу без массовой рассылки. `WONEN123_MONITORING_ENABLED=false` выключает источник без удаления истории.

## Валидация

- Проверяются заголовок Groningen, canonical и поле location. Читаются все страницы по фиксированному шаблону публичного URL; обе навигационные панели должны подтверждать текущую/последнюю страницу и ссылки вперёд/назад.
- JSON-LD ItemList сверяется с числом, порядком, адресами и URL карточек. Промежуточные страницы должны содержать 12 карточек, последняя — 1–12. Проверяется уникальность compound ID (`5423-2`) и URL до применения фильтров. Изменение числа страниц, частичный обход и повреждённые карточки дают ошибку всего прохода.
- Сайт не публикует общий счётчик результатов: `inspected` — сумма проверенных карточек. Перемещение объявлений между страницами без изменения числа страниц и без дублей не всегда обнаружимо.
- Только подтверждённые `Per direct`/корректное `Vanaf DD-MM-YYYY` с месячной ценой, без неизвестных статусов, дают `available`. `verhuurd`, `inoptie`, `gereserveerd` в классе карточки или соответствующий бейдж дают `unavailable`, даже при наличии будущей даты въезда. Неизвестные состояния сохраняются как `unknown`. Только `available` допускает уведомление. Это доступность по данным сайта.
- Slaapkamers — число спален, оно не записывается как общее число комнат. Дата публикации сохраняется из Aangeboden sinds; ограничения по ней нет.
- Реальная пустая выдача ещё не подтверждена: ноль карточек с нулевым ItemList вызывает `EMPTY_SEARCH_UNCONFIRMED`. Валидная полная выдача без подходящих по бюджету объектов может успешно вернуть ноль кандидатов.
- Redirect, challenge, HTTP-ошибки и неверный content-type не становятся пустым успехом. Общий timeout 120 секунд, максимум 100 страниц/12 карточек, пауза 300 мс между страницами, до трёх попыток для transport/502/503/504, тело максимум 8 MiB. 403 блокирует источник, 429 задаёт cooldown.
