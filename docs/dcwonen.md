# DC Wonen

Источник: https://dcwonen.nl/verhuur/page/1. Условия согласованы пользователем 03.11.2026: Groningen, квартиры, студии и дома, без комнат, цена до €1500. Отдельной страницы требований DC Wonen в каталоге Notion на момент подключения нет.

Адаптер: `src/sources/dcwonen-core.ts`, runner и NestJS service рядом; настройки — `scripts/search-modules/dcwonen.cjs`. `DCWONEN_MONITORING_ENABLED=true` по умолчанию. Интервал общий, 900 секунд по умолчанию; отключение и бюджет/площадь доступны через админку.

HTTP выдача содержит пять объектов на странице, общий счётчик и активную страницу пагинации. Коллектор обходит всю выдачу, сверяет счётчики, полноту каждой страницы, стабильность общего количества и уникальность ID/URL. Только после этого выбирает Groningen и типы woning/appartement/studio. Сервер применяет изменяемые минимальную/максимальную цену и минимальную площадь. Смена фильтров использует общий механизм revision/baseline.

Для бюджета берётся показанная цена карточки: inclusief либо exclusief. Коммунальные расходы не вычитаются и не добавляются догадками; это не обязательно kale huur. Название улицы не выдаётся за полный адрес, Max. bewoners не считается числом комнат. Beschikbaar per не считается датой публикации. Наличие в текущей выдаче аренды с датой доступности считается доступностью; явные Verhuurd/Onder optie/Gereserveerd исключают уведомление.

Первый успешный запуск сохраняет baseline без уведомлений о старых объявлениях. Последующие новые подходящие объекты идут через существующий PostgreSQL lease и transactional Telegram outbox. Удаление из выдачи не считается сдачей объекта. HTTP/структурные ошибки не записывают пустой успешный запуск. Редиректы запрещены, тело ограничено 8 MiB, тайм-аут 120 секунд, временные 502/503/504 повторяются максимум трижды; 429 включает cooldown, 401/403 — blocked.

Проверки без БД и Telegram:

```sh
node --import tsx --test test/dcwonen.test.ts
npm run build
node scripts/dcwonen-check.cjs
```

Fixtures содержат только публичную выдачу и пагинацию, без форм регистрации и скрытых токенов. На снимке 03.11.2026: 12 объектов, 3 страницы, 4 подходящих объявления. Live smoke подтверждает только чтение сайта; production-подключение произойдёт после merge/deploy.
