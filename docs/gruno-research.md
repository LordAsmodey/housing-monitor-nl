# Gruno Verhuur — исследование подключения

Дата: 14.10.2026. Статус: технически перспективен; адаптер не реализован и не включён.
Изучены актуальная архитектура в Notion, существующие Woldring runner/service,
ListingsService и публичные страницы через веб-инструмент. Прямой HTTP smoke из
runtime не выполнен: домен отсутствует в разрешённой сетевой конфигурации среды.
Веб-представление не доказывает, что HTML доступен обычному fetch без браузера.

## Подтверждённые наблюдения

- [Каталог Groningen](https://www.grunoverhuur.nl/woningaanbod/groningen)
  содержит форму уточнения: цена, тип, комнаты, площадь, доступность.
  Работу формы и точные GET-параметры фильтров ещё нужно проверить.
- Есть обычные ссылки пагинации: `?moveunavailablelistingstothebottom=true&skip=10`,
  затем `skip=20`, `skip=30`; размер страницы — 10.
  В доступных представлениях разных страниц total расходился (31/36).
  Это может быть разницей времени снимков; изменение количества в live-проходе
  следует обрабатывать как неполную/изменившуюся выдачу, а не успех.
- В списке есть reference ID, адрес, цена, площадь, тип, статус и ссылка.
  Категория Appartement включает Studentenkamer; одного верхнего типа для
  исключения комнат недостаточно. Встречаются semi-zelfstandige студии и
  временные предложения, требующие отдельного решения по включению.
- [Карточка Jozef Israëlsstraat 45-2](https://www.grunoverhuur.nl/woningaanbod/huur/groningen/jozef-israelsstraat/45-2)
  содержит reference 01768, дату публикации (12.10.2026), отдельную дату заселения,
  характеристики и пояснения о составе цены. €1232 уже включает €130 расходов:
  прибавлять servicekosten повторно нельзя.
- [Карточка Briljantstraat 235](https://www.grunoverhuur.nl/woningaanbod/huur/groningen/briljantstraat/235)
  подтверждает, что Studentenkamer вложен в Appartement; описание уточняет общие
  удобства. Площадь в описании и характеристиках может расходиться.
- Публичные сведения доступны веб-инструменту без входа. API/RSS не установлены;
  robots.txt получить через веб-инструмент не удалось. Правила автоматического
  доступа и поведение прямого HTTP остаются непроверенными.

## Предлагаемая интеграция

1. Проверить прямой HTTP из runtime, форму фильтров, robots/условия и сохранённые
   реальные HTML fixtures; только затем выбрать HTTP либо Playwright.
2. Отдельный source `gruno:groningen`, core collector, runner по образцу Woldring
   и Nest service. Переиспользовать runFunda, PostgreSQL lease, baseline и outbox.
3. Сначала валидировать весь каталог и пагинацию, дедуплицировать по reference ID
   и canonical URL без параметров контекста поиска. Детали читать для кандидатов,
   когда нужны дата публикации, состав цены или уточнение самостоятельности жилья.
4. Затем применять фильтры Gruno в адаптере до передачи в ListingsService:
   география, бюджет, тип жилья, доступность и при необходимости дата публикации.
   Общего исполняемого движка фильтров сейчас в ListingsService нет.
   Groningen URL не означает радиус 30 км; критерии Funda не переносить автоматически.
5. Сохранять различие объявленной цены, базовой аренды и включённых расходов.
   Текущий housingDetails/Telegram formatter рассчитан на Woldring и складывает
   rentPrice + serviceCosts: для Gruno потребуется явная семантика цены и изменение
   форматирования с проверкой отсутствия двойного счёта. Не выдавать неизвестную
   дату за сегодня или дату заселения за дату публикации.
6. Первый полный успешный проход — baseline без рассылки. Ошибки структуры,
   статусов и полноты не должны обновлять baseline/lastSuccessAt. Ограниченные
   повторы, cooldown, лимиты страниц/размера/времени и изоляция ошибок источника.

## Проверки перед включением

Реальные fixtures каталога и деталей; пагинация/изменение total; комнаты против
самостоятельных студий; недоступные и неизвестные статусы; локализованные суммы
и даты; включённые расходы; baseline, отсутствие дублей, rollback и отдельный
source lease; live smoke всего прохода без Telegram-рассылки.

Рекомендация: подключение выглядит осуществимым с небольшим отдельным адаптером.
Фильтрацию в модуле стоит оставить даже при работающих фильтрах сайта — особенно
для самостоятельности жилья. До запуска нужно определить критерии именно Gruno
и подтвердить прямое получение страниц; текущая работа — исследование.
