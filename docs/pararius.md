# Pararius — Groningen +25 км

Поиск пользователя: https://www.pararius.nl/huurwoningen/groningen/0-1500/straal-25

Согласовано 17 октября 2026: только отдельное жильё — квартиры, студии и дома. Комнаты исключены. Объявленная месячная аренда до €1500 включительно, без ограничения даты публикации. Если явно указана `Kale huurprijs`, бюджет применяется к базовой аренде. `Totale huurprijs` сохраняется отдельно в JSON-метаданных и отображается отдельной строкой Telegram; разность не выдаётся за servicekosten, поскольку может включать коммунальные услуги. Цена без разбивки остаётся объявленной ценой, без предположений о составе.

Source ID: `pararius:groningen-25km-homes`. Детерминированный browser worker, без LLM. Первая версия использовала Playwright Chromium; подготовлен переход на Chrome через Patchright с persistent-профилем, как у Huurwoningen. Прямой HTTP на исследовании вернул Cloudflare 403 challenge; обычный Chrome открыл выдачу без ручной проверки. Это не подтверждает доступность Playwright в Railway. CAPTCHA требует ручного восстановления через существующий защищённый интерфейс; автоматического решения нет.

Адаптер проверяет Groningen, выбранные цену/радиус, счётчик, ровно 30 карточек на полной странице, остаток на последней, последовательность пагинации, неизменность счётчика и уникальность ID/URL. Обходятся все типы и все страницы; только после полной валидации применяются типы жилья, цена и площадь. Регион делегирован поиску Pararius: окрестные города допускаются. Классификация отдельного жилья основана на типе URL сайта; описания и самостоятельность бытовых помещений отдельно не проверяются.

Непомеченные активные карточки и `Nieuw` считаются доступными по данным Pararius; `Onder optie`, `Verhuurd` и `Gereserveerd` недоступны. Неизвестная метка даёт unknown и запрещает уведомление. Новые доступные объявления и переход к доступности проходят через штатный outbox с дедупликацией. Исчезновение из выдачи само по себе не устанавливает unavailable. Первый успешный запуск формирует отдельный тихий baseline. Lease, scheduler 900 секунд, pause и изменения фильтров используют существующие модули.

URL поиска фиксирован по ссылке пользователя. Админка позволяет сужать цену в пределах €0–1500 и минимальную площадь на сервере; расширение исходного поиска требует изменения адаптера. Ноль без наблюдённого контракта пустой страницы даёт `EMPTY_SEARCH_UNCONFIRMED`; частичная выдача и ошибки не считаются успешным нулём. Ограничения: 20 страниц, 600 карточек, 5 MiB на ответ, до трёх попыток для транспортных ошибок и 502/503/504. 429 задаёт cooldown, 401/403 — BLOCKED. На сбор отводится до 300 секунд; lease — 360 секунд. Неожиданные редиректы отклоняются.

Условия [Pararius](https://www.pararius.nl/info/algemene-voorwaarden), проверенные 17 октября 2026: п. 4.3 оговаривает исключение для личного использования, п. 6.1(d) запрещает коммерческий screen scraping. Реализация предназначена для текущего личного поиска жилья; разрешение на коммерческое использование не подтверждено.

## Развёртывание

Создать отдельный Railway service из того же репозитория с Dockerfile `Dockerfile.pararius-browser`, healthcheck `/health` и собственным volume `/data`. Не использовать volume или ключи других источников. Переменные worker соответствуют существующему браузерному протоколу:

- `BROWSER_PUBLIC_ORIGIN`: HTTPS-домен нового service;
- `BROWSER_WORKER_TOKEN`: случайный секрет не короче 32 символов;
- `BROWSER_STATE_KEY_HEX`: отдельный случайный ключ 32 байта в hex;
- `BROWSER_ACCESS_KEY`: отдельный временный секрет не короче 32 символов;
- `BROWSER_ACCESS_EXPIRES_AT`: срок временного доступа в ISO формате;
- необязательно `BROWSER_IDLE_TIMEOUT_SECONDS=60` для остановки браузера между проходами (по умолчанию выключено).

Browser state зашифрован AES-GCM. Worker закрыт Bearer token; отладочный порт не публикуется. Одноразовая recovery-ссылка действует 24 часа. Main-frame navigation ограничена доменами Pararius, приватные адреса блокируются. В варианте Chrome сторонние ресурсы сохраняются, как у Huurwoningen; Cloudflare challenge остаётся доступен для ручной проверки.

До включения приложения выполнить read-only smoke (без БД и Telegram):

```sh
node --env-file=.env scripts/pararius-check.cjs
```

Для этого локально настроить `PARARIUS_BROWSER_ORIGIN` и `PARARIUS_BROWSER_TOKEN`. При challenge открыть выданную worker recovery-ссылку, пройти проверку вручную, открыть «Поиск жилья» и сохранить сессию. Затем повторить smoke. В приложении задать оба этих значения для включения источника. Без них источник не запускается, и админка показывает отсутствие runtime. Удаление пары выключает runtime без сброса истории; обычная пауза — через админку.

## Подготовка Chrome как у Huurwoningen

По предложению пользователя от 18 октября Pararius переводится на headed Google Chrome через Patchright 1.63.0 из существующего lockfile `browser-experiment`. Как у рабочего Huurwoningen, используется persistent context, окно 1024×768, ожидание страницы 5 секунд и зашифрованный полный профиль. Между страницами — пауза 5 секунд. Прокси не добавляется.

Source ID, отдельный volume `/data` и ключи Pararius сохраняются. Chrome-профиль сохраняется в `/data/chrome-profile.enc`; plaintext существует только во временной папке контейнера. При первом переходе переносятся cookies из имеющегося зашифрованного storageState; полный профиль Huurwoningen не копируется. Последующие перезапуски восстанавливают собственный архив Chrome и свежие session cookies. Ручные Cloudflare-проверки остаются ручными; новый движок ещё не доказал успешный полный проход Pararius.

CI дополнен тестом реального `launchProfile`: создание Chrome-профиля, закрытие, шифрование, восстановление cookies и localStorage без внешней сети. Healthcheck Chrome сообщает engine и точный release SHA. Для проверки после развёртывания выдержать cooldown после 429, затем выполнить read-only smoke. Если понадобится проверка человека, выполнить её в интерфейсе worker. Настройки основного приложения пока не включать.

## Повторная загрузка первой страницы

После новой ручной проверки в Chrome 18 октября в 18:04 Europe/Amsterdam состояние снова было валидным (`humanCheck=false`, `searchReady=true`, `recovered=true`), но полный collector получил `ACCESS_BLOCKED` при немедленной повторной загрузке той же первой страницы. Подготовлено устранение лишнего запроса: только Pararius может прочитать уже открытый документ, если его фактический main-frame HTTP-ответ был успешным, точный URL совпадает с исходным поиском, после DOMContentLoaded прошло не более 60 секунд и полный parser этой страницы подтвердил выдачу. Последующие страницы всегда навигируются обычным способом. Состояние 403/429, неизвестный HTTP-ответ, устаревшая или невалидная страница не переиспользуются. После этого коллектор всё равно проверяет счётчик, все страницы, дубли и фильтры. Это уменьшает число запросов, но не гарантирует отсутствие Cloudflare; обязательные проверки человека не автоматизируются.
