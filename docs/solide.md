# Solide Verhuur

Источник: [пользовательская выдача](https://solideverhuur.nl/?action=epl_search&post_type=rental&property_location=20&property_price_to=1500).
Source ID: `solide:groningen-rental`.

Groningen (`property_location=20`), аренда до €1500, без ограничения даты публикации и типа жилья. Цена передаётся в поиск сайта. Не добавляем радиус или ограничение «за сегодня» от других источников. Стоимость услуг не раскрывается в карточках и не прибавляется к цене.

Сбор выполняется обычным HTTP GET без аккаунта и browser worker. На 15.10.2026 robots.txt запрещает только `/wp-admin/` и не запрещает используемую выдачу. Это проверка robots.txt, а не подтверждение отдельных условий использования.

HTML содержит счётчик результатов, по 10 карточек на страницу и ссылки `/page/N/`. Адаптер проверяет форму аренды, выбранный Groningen, отображённые цены, когда они представлены в dropdown, счётчик, активную страницу, ссылки пагинации и точное количество карточек. Цены, отсутствующие в dropdown, принимаются backend сайта без выбранной опции. Все страницы читаются последовательно с паузой 250 мс. Изменившийся счётчик, дубликаты ID/URL, пропущенная страница, повреждённая карточка, HTTP/challenge и слишком большой ответ завершают весь проход ошибкой. Число страниц ограничено 200, ответ — 8 MiB, сбор — 120 секундами. Для сетевых ошибок и 502/503/504 предусмотрено до трёх попыток; 429 получает cooldown. Частичный сбор не сохраняется как успех.

`post-N` задаёт внешний ID. Из карточки читаются адрес, город, месячная цена и жилая площадь. Число спален не подменяет общее число комнат; дата заселения не подменяет дату публикации. У сданных объектов цена может отсутствовать. `epl-status-current` подтверждает доступность; `under-reservation`/«Onder optie» и `leased`/«Verhuurd» исключают уведомления. Неизвестный статус сохраняется как unknown без отправки. У явно доступного объекта обязательны положительная цена и площадь. Ссылки ограничены HTTPS и `/huurwoningen/groningen/.../` на `solideverhuur.nl`.

NestJS использует общий PostgreSQL lease, расписание `MONITOR_INTERVAL_SECONDS` (по умолчанию 900 секунд), отдельный baseline и transactional Telegram outbox. Первый полный проход тихо сохраняет старые объявления. В админке доступны цена от/до, минимальная площадь и pause; площадь проверяется перед уведомлением. Изменение настроек подавляет исторические уведомления штатным механизмом. `SOLIDE_MONITORING_ENABLED=false` выключает источник без сброса baseline.

Проверки:

```sh
node --import tsx --test test/solide.test.ts
npm run build
node scripts/solide-check.cjs
```

Последняя команда читает все реальные страницы без БД и Telegram. На 15.10.2026: 56 объектов, 6 страниц, 5 доступны. Fixture содержит настоящую форму, карточки и пагинацию первой/последней страницы; нулевая выдача получена с диапазоном €19000–20000. Тест транспорта использует сокращённый до двух страниц каталог из этих карточек.

Локально прошли unit-тесты, typecheck и сборка. PostgreSQL integration подготовлен, но не выполнен: Docker не может создать одноразовый контейнер из-за read-only filesystem. Production-развёртывание, штатный baseline и естественная доставка нового объявления этой проверкой не подтверждены.
