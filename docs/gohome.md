# GoHome

Groningen, объявленная месячная аренда €500–1500 включительно, отдельное жильё
без комнат и общих удобств. Без ограничения даты публикации. Студенческая и
временная аренда не исключаются автоматически: пользовательская ссылка не
содержит таких ограничений. Дополнительные расходы к фильтру цены не прибавляются.

`gohome:groningen-homes` использует публичный JSON API без аккаунта, cookies,
Chromium и LLM. `f` в исходной ссылке — Base64URL JSON фильтров, не секрет.
[Исследование и правила сайта](research/gohome-2026-10-19.md).
После исследования пользователь поручил подключить мониторинг и подготовить PR;
отдельное разрешение от GoHome не предоставлялось. robots.txt не запрещает пути;
условия содержат ограничения коммерческого scraping и копирования информации.

## Запуск и управление

Источник включён по умолчанию после развёртывания. `GOHOME_MONITORING_ENABLED=false`
отключает его без потери истории. В админке доступны цена от/до, минимальная площадь
и pause. Цена отправляется в JSON body API и повторно проверяется локально;
площадь проверяется по структурированным данным. Неизвестная площадь не проходит
активный фильтр площади. Ссылка поиска в админке генерируется из тех же настроек.

Scheduler — 900 секунд; PostgreSQL lease 300 секунд, бюджет коллектора 240 секунд.
Первый полный успешный запуск создаёт отдельный baseline без уведомлений.
Последующие новые доступные объявления и переходы в доступность используют
существующий transactional Telegram outbox и его дедупликацию.
Новых миграций и отдельного Railway/browser сервиса не требуется.

## Проверки и ограничения

Коллектор читает все страницы по 15 и детали всех объектов, включая сданные.
Проверяет общий счётчик, размеры страниц, итоговое количество, уникальность ID
и slug, город, цену, страну и согласованность деталей с карточкой. Неизвестный
тип жилья и описания с явными признаками комнат/общих удобств исключаются.
Типы APARTMENT, STUDIO и HOUSE допускаются. Только явные isRented=false,
published=true и offerType=RENTAL дают available. Неизвестный статус не уведомляется.
Это доступность на GoHome, а не независимая проверка у арендодателя.

Пустой ответ проверен контрольным поиском: totalPropertiesCount=0, properties=[].
Сбой HTTP, неверный JSON/схема, ошибка деталей, неполная пагинация или смена total
не обновляют baseline/последний успех. 401/403 блокируют источник, 429 дают cooldown;
редиректы не следуются, запросы ограничены известными API путями, телом 4 MiB
и временем. 502/503/504 и транспортные ошибки имеют максимум три попытки.
Между страницами/деталями пауза 250 мс. Snapshot-консистентность API не доказана.

Описание не используется для догадок о площади, полной стоимости или дате.
Пример: minimumRent=1083, а описание дополнительно указывает отопление и servicekosten;
объявленная цена не выдаётся за полную стоимость. У одного объекта дата заселения
в структурированных данных расходится с одним пунктом описания. Дата публикации
не выводится из createdTimestamp. Условия участия в студенческой/временной аренде
нужно читать по ссылке объявления; уведомления не содержат полный текст описания.

```sh
npm run typecheck
node --import tsx --test test/gohome.test.ts
node --import tsx scripts/gohome-check.cjs
# На отдельной тестовой PostgreSQL с применёнными миграциями:
npm run test:integration
```

Live smoke не подключается к БД и Telegram. GitHub workflow `GoHome live smoke`
проверяет полный обход API в PR. Production включится после слияния и развёртывания;
до этого локальный smoke не доказывает production baseline или доставку Telegram.
