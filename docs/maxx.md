# Maxx Huren

Источник: [пользовательская выдача](https://maxxhuren.nl/woonruimte-huren/?city=Groningen&type=&max=1500).
Source ID: `maxx:groningen-homes`.

По уточнению пользователя: Groningen, только отдельное жильё — Appartement, Studio, Bovenwoning, Eengezinswoning. Kamer, Garage, Berging, Overige и неизвестные типы исключаются. Дата публикации не ограничивается. Максимальная объявленная аренда — €1500/месяц включительно. Цена берётся из выдачи; дополнительные расходы в описаниях не прибавляются. Например, Bernoulliplein 23 показывает €875 в выдаче, а описание отдельно указывает €165 за коммунальные услуги.

Один публичный HTTP GET возвращает полный каталог по фильтрам; браузер и аккаунт не нужны. На 16.10.2026 robots.txt разрешает доступ для User-agent `*`, кроме перечисленных отдельно ботов. Это не подтверждение отдельных условий использования. Адаптер не выполняет заявки и не посещает закрытые страницы.

Максимальная цена передаётся параметром `max`, город — `city=Groningen`, `type=` остаётся пустым: сначала проверяется полнота всех объектов, затем отбираются согласованные типы жилья. Проверяются эхо фильтров в форме, заголовок, счётчик, контейнер, точное количество карточек, уникальность ID/URL, город, цена, площадь и комнаты. Пагинации в исследованной выдаче нет; неполный каталог завершается ошибкой. Ноль принимается только при валидной форме, нулевом счётчике, пустом контейнере и явном сообщении «Er zijn geen woningen gevonden met deze filters.».

ID берётся из `/objects/ads/view/id-ID/` и сверяется с `id="object-ID"`. URL разрешены только HTTPS на `maxxhuren.nl`, с указанным путём, без query/fragment. Нидерландская цена `€1.465,00` читается как €1465. Отсутствующее число перед `m²`/`kamers` сохраняется как неизвестное: на реальном сайте это есть у Schilderswijk 0 и нежилых объектов. Исчезновение самого поля и некорректное значение завершают проход ошибкой.

Только `Beschikbaar` и `Nieuw - Beschikbaar` с классом `object-beschikbaar` подтверждают доступность. `Bijna verhuurd` и `Reeds verhuurd` недоступны; неизвестные и противоречивые статусы не уведомляются. Полный проход должен завершиться до записи в БД. Challenge, redirects, HTTP-ошибки, дубликаты и повреждённая выдача не считаются пустым успехом. До трёх попыток при сетевой ошибке/502/503/504, cooldown при 429; 120 секунд и 8 MiB на ответ.

Штатный NestJS scheduler использует PostgreSQL lease, интервал 900 секунд, отдельный тихий baseline и transactional Telegram outbox. Первый проход сохраняет историю без рассылки старых объявлений. `MAXX_MONITORING_ENABLED=false` выключает источник без сброса baseline.

Админка предоставляет pause, аренду от/до и минимальную площадь. Максимум соответствует опциям сайта: €500–2500 с шагом €100. Минимальная цена и площадь применяются перед уведомлением; неизвестная площадь не проходит заданный минимум. Изменение настроек использует штатное подавление исторических уведомлений.

Проверки:

```sh
node --import tsx --test test/maxx.test.ts
npm run build:all
node scripts/maxx-check.cjs
```

Smoke читает сайт без БД и Telegram. На 16.10.2026: inspected=65, matched=33, available=3. Доступны Bernoulliplein 23 (€875, 29 м²), Floresplein 10-A (€645,78, 24 м²), Schilderswijk 0 (€1000, площадь неизвестна).

Fixture содержит публичный каталог с формой и счётчиком; пустые/повреждённые варианты в тестах синтетические на основе реальной разметки. Пустое состояние отдельно исследовано реальным GET `max=1`; это значение не является поддерживаемой опцией формы и не предлагается в админке.

Локально прошли 121 unit-тест, TypeScript/build, React build, Prisma validate и live smoke. Добавлен PostgreSQL integration: baseline, повторный проход, строгая доступность, дедупликация, фильтр площади, отключение и сохранение состояния при ошибке. Локальный Docker не создал временную БД из-за read-only storage; интеграционная проверка выполняется в CI. Production и доставка нового естественно появившегося объявления требуют проверки после выпуска.
