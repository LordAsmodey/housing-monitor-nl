# План и технический долг

Актуальный план ведётся в [Notion: Backlog](https://app.notion.com/p/402d10c6e6ab815983ddf6700505fc7c?pvs=204); критерии готовности — на [странице MVP](https://app.notion.com/p/402d10c6e6ab81ce8707f7bab329ead7?pvs=204). Этот файл служит указателем, а не вторым независимо обновляемым планом.

## Ориентиры

- MVP без LLM: HTTP/JSON/Playwright, валидация, ограниченные повторы, диагностика и ручное восстановление.
- Scheduler/lease и доставка уже работают через PostgreSQL; React-админка и настройки поиска реализованы. Не создавать их заново по старому backlog.
- Приоритеты — стабильность действующих источников и доставка, диагностика исходных ошибок, корректные события повторной доступности и постепенный перенос оставшейся CJS-логики в strict TypeScript.
- Источник с авторизацией и длительная приёмка MVP остаются неподтверждёнными. Само количество источников не закрывает эти критерии.
- Подписки нескольких пользователей, развитие registry и очередей, LLM self-healing — отдельные дальнейшие работы по условиям профильного плана.

Подробные задачи и критерии готовности не дублируются здесь. [Исходный локальный план](archive/roadmap-history.md) сохранён для истории. Если Notion недоступен, используйте этот ориентир и код, явно обозначив ограничение актуальности.
