# Rentola — Groningen

Источник: https://rentola.nl/en/rent?location=240117&order=desc

Согласовано 17 октября 2026: Groningen, объявленная месячная аренда до €1500 включительно, только отдельное жильё без комнат. Дата публикации не ограничена. Дополнительные расходы из описаний не прибавляются к цене. Source ID: `rentola:groningen-homes`.

Публичный HTTP GET, без аккаунта и browser worker. Заголовок `Accept-Language: en` соответствует URL; с `nl-NL` сайт перенаправляет на `/huren`, такой редирект не принимается. Цена и минимальная площадь применяются на сервере, исходная ссылка сохраняется. Обходятся все страницы, включая объекты за пределами бюджета: на исследовании 285 объектов, 14 страниц, по 21 объекту. Число страниц ограничено 100, тело ответа — 8 MiB, время всего прохода — 140 секунд. Страницы читаются последовательно с паузой 300 мс. Описания — партиями до двух запросов, со сдвигом старта 300 мс и паузой 300 мс между партиями; обе операции завершаются до возврата ошибки. HTTP 502/503/504 и транспортные сбои повторяются до трёх попыток; 429 даёт cooldown, 401/403 — BLOCKED.

Адаптер декодирует строковые `self.__next_f.push` как JSON, не исполняет JavaScript. Проверяет эхо location/order/page, отсутствие неожиданных фильтров, город карточек и included, пагинацию, полноту, уникальность ID/URL внутри страницы и между страницами. JSON-LD сверяется с публичным состоянием: URL, название, цена, валюта и адрес. Смена счётчика во время обхода приводит к ошибке. Частичный ответ, редирект, challenge и ошибка не считаются успешным нулём. Реальный пустой ответ для этой выдачи пока не подтверждён; ноль завершается `EMPTY_SEARCH_UNCONFIRMED`.

Категории Rentola ненадёжны: реальная карточка Jennerstraat 12 помечена `apartment`, но описание предлагает три студенческие комнаты. Поэтому категории `room`, `student apartment`, неизвестные и неоднозначные типы исключаются; проверяются названия и описания всех кандидатов в пределах цены/площади. Комнаты, совместные бытовые помещения и признаки несамостоятельного жилья исключаются. Неоднозначный `house` без явного названия жилья исключается. Объявления с явно пустым описанием исключаются, так как самостоятельность жилья подтвердить нельзя. Правила консервативны: упоминание отдельных комнат в описании может исключить и полноценное жильё. Типы и описания остаются утверждениями агрегатора; фактическая доступность у исходного арендодателя не подтверждается.

Только `https://schema.org/InStock` одновременно в выдаче и описании допускает объект. Чужие домены, credentials, query/hash в detail URL запрещены. Поддерживаются новые slug с `-p…` и старые с шестизначным hex suffix. Оценочная площадь не используется как известная; при заданном минимуме объект без достоверной площади исключается. Ссылка ведёт на Rentola; платный контакт с арендодателем не используется.

Штатный runner обеспечивает PostgreSQL lease, расписание 900 секунд, отдельный тихий baseline и transactional Telegram outbox. Первая успешная загрузка сохраняет объявления без рассылки. Админка: pause, аренда от/до, минимальная площадь. `RENTOLA_MONITORING_ENABLED=false` выключает источник без сброса истории.

Fixtures: сокращённые реальные публичные данные первой и последней страницы и реальное описание ошибочно классифицированной комнаты. Unit-тесты проверяют границы цены/площади, исключение комнат, полноту, смену счётчика, дубли и отказные HTTP-сценарии. PostgreSQL integration проверяет независимый baseline, отсутствие дублей, availability, фильтры и сохранность истории после ошибки. CI запускает integration на временной БД; live smoke workflow не пишет в БД и не отправляет сообщения.

На локальной проверке Docker не смог создать временную PostgreSQL (`read-only file system` в overlay2); локальная интеграционная проверка не подтверждена. Production deployment и первый штатный baseline ещё не выполнены.

Живой smoke 17 октября 2026 успешно завершён: inspected=285, matched=68, pages=14, время 95,086 секунды. Все 68 прошли проверку описания и InStock; это заявления Rentola о доступности. Запросы выполнены свежими, без HTTP-кэша адаптера, без БД и Telegram. Полный локальный unit-набор: 136/136; typecheck, backend build, React admin build и Prisma validate успешны. Production-мониторинг и реальная доставка новых объявлений этим smoke не подтверждаются.
