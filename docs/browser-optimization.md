# Снижение памяти браузерных worker

Подготовлен включаемый режим остановки Chromium между проверками. HTTP-сервер
и Xvfb остаются доступны; расписание приложения сохраняется (900 секунд).
Браузер запускается при следующем авторизованном запросе worker или UI.

## Включение и возврат

`BROWSER_IDLE_TIMEOUT_SECONDS=60` закрывает браузер через 60 секунд без запросов.
Допустимы целые значения 10–3600; `0` или отсутствие переменной сохраняет
постоянно работающий браузер. Переменная относится к browser service, не приложению.
Для Chrome Huurwoningen observer должен быть выключен:
`BROWSER_EXPERIMENT_ENABLED=false`. Совмещение observer и idle отклоняется при старте.

Сначала включить на одном worker и подтвердить несколько полных циклов
сбора → idle → восстановление → сбор. Проверить число объявлений, полноту страниц,
статус источника и отсутствие повторов outbox. Повторный запуск браузера может
повлиять на проверку человека; локальный smoke не доказывает стабильность Cloudflare.
При регрессии вернуть `BROWSER_IDLE_TIMEOUT_SECONDS=0` и развернуть прежний
проверенный образ. Volumes, ключи шифрования и Source ID сохранять.

Huurwoningen Chrome worker собирается из Git Dockerfile; новые модули включены
в Dockerfile и список committed artifact exporter. Funda пока использует старый
bootstrap: изменение Git само по себе не обновляет его Start Command. Перед
включением обновить команду из проверенного коммита через
`scripts/funda-browser-bootstrap.cjs`; генератор включает модули lifecycle/resources.
Миграция Funda на Docker-образ из Git остаётся отдельной задачей.

## Состояние и измерения

`GET /health` сообщает `browserState` (`active`, `idle`, `failed`, `stopped`) и
`idleTimeoutSeconds`, не запуская браузер. `idle` возвращает 200: worker готов принять
работу. Ошибка остановки/сохранения возвращает 503 и блокирует запуск со старой
сессией. Очередь общая для сборов, ручного управления и остановки; браузер не
закрывается посреди выполняемой операции. Опрос ручного UI продлевает время работы;
heartbeat не продлевает простой и не будит браузер.

Перед остановкой Funda сохраняет AES-GCM storageState с IndexedDB. Chrome
Huurwoningen закрывает persistent context, сохраняет полный профиль в зашифрованный
архив и удаляет временную plaintext-копию после успешного сохранения. Следующий
запуск восстанавливает архив; лишние восстановленные вкладки закрываются.

Логи `collection-resources-start`, `collection-resources-end` и `browser-resources`
содержат RSS Node, доступное измерение памяти cgroup и число Chrome/Chromium процессов.
`durationMs` измеряет сбор после запуска браузера; startup логируется отдельно.
На системах без `/proc`/cgroup соответствующие поля отсутствуют. Секреты, URL,
командные строки процессов и содержимое профиля в эти измерения не включаются.

После production-включения сравнить среднюю RAM Railway за одинаковые интервалы
48–72 часа, продолжительность сборов и частоту BLOCKED. Обещать экономию до измерений
нельзя: память cgroup включает файловый кэш, а Xvfb/Node остаются запущены.

## Аудит 14 октября 2026

Прочитан актуальный документ Notion и обсуждение оптимизации. Метрики Railway
за час на момент аудита: Funda avg 1.716 GB, старый Huurwoningen avg 1.183 GB,
production Patchright Chrome avg 0.663 GB. Это baseline до изменений.
Patchright теперь production-источник, несмотря на слово experiment в имени.
Старый Huurwoningen — кандидат на остановку после подтверждения фактического
`HUURWONINGEN_BROWSER_ORIGIN` и отсутствия потребителей. OAuth connector возвращает
только имена переменных; зависимость по значению через него не проверена.
Volumes и сервисы не удалять для экономии. Режим idle по умолчанию выключен;
production-конфигурация в рамках подготовки не менялась.

## Проверка образа

Для сборки на Mac с Apple Silicon указать `--platform linux/amd64`: production
Google Chrome не поддерживает Linux arm64. В CI после Docker build выполняется
`scripts/browser-profile-smoke.cjs` в контейнере без внешней сети. Smoke поднимает
локальную страницу, записывает тестовые cookies/localStorage/IndexedDB, закрывает
Chrome, сохраняет зашифрованный профиль и проверяет все три хранилища после запуска.
Также проверяется отсутствие Chrome-процессов в idle. Это тестовые данные без
production-ключей, сайтов, БД и Telegram.
